## [0.5.0] - 2026-10-30

### Added
- Institutional evidence registry with three initial records.
- Read-only `/api/v1/evidence` endpoint.
- Evidence query engine with entity filtering.
- Data-quality auditing and optional DNS checks.
- Automated evidence validation and HTTP API tests.

### Security and governance
- Explicit unverified domain ownership status.
- Rejection of invalid and repeated Evidence API parameters.
- Separation of registry consistency from authoritative verification.

## v0.4.0 - 2026-10-30

### Added
- Institutional registry for Yemeni ministries and universities.
- Searchable national registry engine.
- HTTP search endpoint with pagination.
- Institution validation and registry synchronization checks.
- Automated API and registry tests.

### Data
- 22 governorates.
- 335 districts.
- 10 ministry records.
- 3 university records.
- 370 total entities.

### Notes
- Independent, unofficial prototype.
- Proposed domains are not proof of registration.
- Observed domains are not proof of ownership.
- Institutional records require ongoing source verification.
